# 12-Column Grid Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship an explicit 12-column CSS grid system and migrate all site pages to use it with full mobile stacking.

**Architecture:** Shared stylesheet defines `.grid` + span/start utilities at `sm`/`md`/`lg` breakpoints. HTML sections nest `.grid` inside `.container` and assign column classes. Legacy layout classes (`two-col`, `card-grid--*`, `hero__grid` as layout, `footer-grid` columns, etc.) are removed or reduced to non-layout styling.

**Tech Stack:** Static HTML, single `css/style.css`, no build step.

---

### Task 1: Add 12-column grid system to CSS

**Files:**
- Modify: `css/style.css` (layout section ~142–153; add utilities; strip layout from component grids)

**Step 1:** Replace `.grid-16` with `.grid` (12 columns, gap, `> *` default full span + `min-width: 0`).

**Step 2:** Add `.col-1`…`.col-12`, responsive `sm`/`md`/`lg` variants, and matching `.col-start-*` utilities.

**Step 3:** Remove layout `grid-template-columns` / flex row rules from `.hero__grid`, `.card-grid`, `.steps`, `.footer-grid`, `.two-col`, `.credentials`, `.gallery-grid` (keep visual styles: cards, step numbers, footer colours).

**Step 4:** Spot-check stylesheet: no remaining `grid-16`; breakpoints match design (480 / 768 / 900).
